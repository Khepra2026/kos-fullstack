# KOS REGULATORY ZERO-DEFECT PROTOCOL™

> **Norme Suprême KOS n°001 — Charte de Crédibilité Réglementaire Big Four**
> 
> **Statut** : PERMANENT · IRRÉVOCABLE · OPPOSABLE À TOUS LES AGENTS KOS
> 
> **Date d'entrée en vigueur** : 25 Juin 2026
> 
> **Autorité émettrice** : Managing Partner — KHEPRA EXPERTS
> 
> **Portée** : Tous les hubs KOS, toutes les pages publiques, tous les observatoires, tous les contenus réglementaires, tous les articles de blog, tous les livrables, toutes les réponses IA.

---

## MISSION FONDAMENTALE

Protéger la réputation, la crédibilité et la responsabilité professionnelle de KHEPRA EXPERTS.

### Principe absolu :

**Aucune publication, analyse, alerte, étude, article, dashboard, formation, FAQ, réponse IA ou livrable client ne peut contenir :**

- ❌ un texte inexistant ;
- ❌ une référence non vérifiée ;
- ❌ une numérotation erronée ;
- ❌ une date erronée ;
- ❌ une autorité de régulation erronée ;
- ❌ une interprétation empirique ;
- ❌ une extrapolation ;
- ❌ une hypothèse présentée comme un fait.

## PRINCIPE N°2 — TRIPLE VALIDATION OBLIGATOIRE

### Niveau 1 — Agent Regulatory Intelligence

| Attribut | Valeur |
|----------|-------|
| **Mission** | Identifier le texte officiel |
| **Validation requise** | Numéro exact, date exacte, autorité émettrice, version officielle |
| **Statut produit** | **SOURCE IDENTIFIÉE** |

### Niveau 2 — Agent Regulatory Verification

| Attribut | Valeur |
|----------|-------|
| **Mission** | Comparer le texte avec la publication officielle |
| **Validation requise** | Intégrité du texte, version en vigueur, statut juridique, abrogation éventuelle, modification éventuelle |
| **Statut produit** | **SOURCE CERTIFIÉE** |

### Niveau 3 — Agent Legal & Compliance Review

| Attribut | Valeur |
|----------|-------|
| **Mission** | Valider la citation et la portée juridique |
| **Validation requise** | Exactitude juridique, contexte réglementaire, limites d'application, juridiction concernée |
| **Statut produit** | **SOURCE PUBLIABLE** |

> **Règle** : Seul un texte ayant franchi les 3 niveaux de validation peut être publié sous marque KHEPRA.

## PRINCIPE N°3 — NOMENCLATURE OBLIGATOIRE

Toute citation doit suivre le format :

```
[Autorité]
[Type de texte]
[Numéro]
[Date]
[Titre officiel]
[Statut]
```

### Exemple :

```
BCEAO
Instruction n°001-04-2018
du 10 avril 2018
relative au contrôle interne et à l'audit interne des SFD
Statut : En vigueur
```

> **Règle** : Toute référence incomplète est REJETÉE.

## PRINCIPE N°4 — INTERDICTION D'INTERPRÉTATION

### KOS ne doit JAMAIS écrire :

| ❌ Interdit | ✅ Autorisé |
|------------|------------|
| "Le texte exige probablement..." | "Le texte prévoit expressément que..." |
| "Le régulateur entend certainement..." | (reproduire la référence exacte) |
| "Cette disposition signifie que..." | (citer le texte + référence) |

> **Règle** : Toute analyse doit être SÉPARÉE du texte réglementaire.

---

## PRINCIPE N°5 — GESTION DES TEXTES EN PROJET

### Catégories autorisées :

| # | Catégorie | Définition |
|---|-----------|------------|
| 1 | **En vigueur** | Texte applicable et opposable |
| 2 | **Publié mais non applicable** | Texte publié mais dont l'entrée en vigueur est différée |
| 3 | **Projet de texte** | Texte en cours d'élaboration, non publié officiellement |
| 4 | **Consultation publique** | Texte soumis à consultation, non adopté |
| 5 | **Rumeur non vérifiée** | Information non confirmée par source officielle |

### Mention obligatoire pour les projets :

> **"Projet de texte — sans valeur normative à ce stade."**

> **Règle** : Un projet ne peut JAMAIS être présenté comme un texte applicable.

## PRINCIPE N°6 — MOTEUR D'ALERTE RÉPUTATIONNELLE

### Déclenchement automatique si :

| Condition | Action |
|-----------|--------|
| Référence non vérifiée | **Publication bloquée** |
| Numéro introuvable | **Publication bloquée** |
| Citation incomplète | **Publication bloquée** |
| Source non officielle | **Publication bloquée** |
| Contradiction entre deux textes | **Publication bloquée** |

### Statut déclenché :

> **ESCALADE RÉGLEMENTAIRE** — Contenu gelé. Validation Managing Partner requise.

| 4 | **Date** (JJ/MM/AAAA) | ✅ |

## PRINCIPE N°8 — INDICE DE FIABILITÉ KOS

Chaque contenu réglementaire reçoit une note :

| Score | Signification | Publication ? |
|-------|--------------|---------------|
| **100** | Source officielle validée — Texte vérifié sur site du régulateur | ✅ Publiable |
| **95** | Source officielle validée — En attente de revue juridique | ✅ Publiable |
| **75** | Source officielle en attente de revue — Texte identifié mais non certifié | ⚠️ Interne uniquement |
| **50** | Source secondaire — Information relayée mais non vérifiée sur source primaire | ❌ Bloqué |
| **25** | Source non vérifiée — Information non confirmée | ❌ Bloqué |
| **0** | Source interdite — Blog, média, réseau social, IA | ❌ Bloqué |

> **Règle** : Seuls les contenus ≥ 95 peuvent être publiés sous marque KHEPRA.

## ARTICLE 10 — GOUVERNANCE DU PROTOCOLE

### 10.1 Responsable Conformité Réglementaire

Le **KOS Regulatory Citation Validator™** est l'agent responsable de la vérification continue des citations réglementaires conformément aux 9 Principes.

### 10.2 Audit périodique

| Fréquence | Action |
|-----------|--------|
| **Quotidien** | Scan des alertes réglementaires — vérification des nouvelles citations |
| **Hebdomadaire** | Vérification des sources des Edge Functions RAG |
| **Mensuel** | Scan de tous les mocks pour détecter les références potentiellement invalides |
| **Trimestriel** | Vérification de toutes les pages publiques |
| **Annuel** | Audit complet par un tiers indépendant |

### 10.3 Classification des infractions

| Niveau | Description | Action |
|--------|-------------|--------|
| **CRITIQUE** | Texte inexistant cité comme réel, fausse référence, source non officielle | Correction immédiate + audit complet du contenu + ESCALADE Managing Partner |
| **MAJEURE** | Texte réel mais référence erronée (numéro, date, autorité), interprétation spéculative | Correction sous 24h + vérification contenus similaires |
| **MINEURE** | Métadonnées incomplètes, URL manquante, date de vérification absente | Correction sous 7 jours |

### 10.4 Traitement des infractions

1. Toute infraction détectée → création d'un ticket KOS Auto-Correction
2. Correction immédiate du contenu concerné
3. Vérification des contenus similaires (même régulateur, même domaine)
4. Mise à jour de la base de connaissances RAG
5. Documentation de la correction dans le journal d'audit KOS
