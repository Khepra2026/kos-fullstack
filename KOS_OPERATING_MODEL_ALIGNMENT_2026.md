## PHASE 4 — MONETIZATION MODEL CORRECTION

### 4.1 Hidden Pricing Logic (INTERNE UNIQUEMENT)

Les grilles tarifaires existent mais ne sont JAMAIS exposées publiquement. Elles sont :
- Stockées dans les outils CRM internes
- Communiquées uniquement dans les propositions commerciales
- Adaptées à chaque client

### 4.2 Sales Pipeline Logic (Offline Only)

```
ÉTAPE 1 : Entrée (diagnostic / contenu / observatoire)
  → Le prospect découvre KOS via un contenu, un outil ou l'observatoire
  → Aucun prix visible, aucun engagement

ÉTAPE 2 : Qualification (formulaire stratégique)
  → Le prospect remplit un formulaire de qualification
  → Les informations sont envoyées à l'équipe commerciale

ÉTAPE 3 : Expert Review
  → Un Directeur BU analyse le besoin
  → Évaluation de la complexité et des ressources nécessaires

ÉTAPE 4 : Entretien Confidentiel
  → Appel ou visioconférence de 30-45 minutes
  → Clarification du scope, attentes, budget

ÉTAPE 5 : Proposition de Mission (Devis)
  → Proposition commerciale détaillée envoyée sous 72h
  → Devis confidentiel avec scope, livrables, délais, conditions

ÉTAPE 6 : Contract Signature
  → Contrat signé électroniquement
  → Conditions générales + annexes techniques

ÉTAPE 7 : Delivery
  → Équipe dédiée, méthodologie KOS
  → Livrables documentés, assurance qualité
  → Facturation selon échéancier contractuel
```

## PHASE 5 — TRUST & INSTITUTIONALIZATION FRAMEWORK

### 5.1 Approved Institutional Wording Library

| Domaine | Formulation approuvée |
|---------|----------------------|
| Mission | « Mission d'intelligence réglementaire » |
| Équipe | « Équipe dédiée dirigée par un Directeur de Business Unit » |
| Qualité | « Validation croisée Director + Quality Assurance » |
| Méthodologie | « Protocole documenté, traçabilité complète, normes ISA/ISAE/COSO » |
| Délais | « Délais contractuels garantis » |
| Tarification | « Devis confidentiel sur mesure » |
| Engagement | « Engagement contractuel » |
| Référence | « Mission de référence » (pas « client ») |

### 5.2 Forbidden Wording List

| Terme interdit | Raison |
|---------------|--------|
| « SaaS », « Software as a Service » | Auto-identification incompatible |
| « Abonnement », « Subscribe » | Signal récurrent SaaS |
| « Essai gratuit », « Free trial » | Signal self-service |
| « Pricing », « Plans », « Tarifs » | Exposition prix |
| « MRR », « ARR », « ARPU » | Métriques SaaS |
| « Self-service » | Incompatible avec modèle expert |
| « Checkout », « Paiement en ligne » | Signal e-commerce |
| « Automatique » (pour pricing/facturation) | Signal SaaS |
| « Plateforme » (seul, sans contexte) | Préférer « Système » ou « Écosystème » |
| « Produit » (pour les offres) | Préférer « Mission », « Engagement », « Service » |

### 5.3 Credibility Compliance Checklist

- [ ] Aucun prix visible publiquement
- [ ] Aucune référence à un abonnement SaaS
- [ ] Aucun CTA d'achat ou d'essai
- [ ] Tous les CTAs mènent à un contact humain
- [ ] Toutes les statistiques sont sourcées ou vérifiables
- [ ] Le ton est institutionnel, pas marketing
- [ ] Les normes professionnelles sont citées (ISA, ISAE, COSO, GAFI)
- [ ] La validation experte est mentionnée sur chaque offre
- [ ] Les mentions légales et déontologiques sont à jour
