## 2. STANDARDS ÉDITORIAUX

### Format Article

| Élément | Standard |
|---------|----------|
| Longueur | 1500 - 3000 mots |
| Structure | H1 → H2 → H3 → H4 |
| Ton | Institutionnel (niveau 3-4) |
| Références | Chaque affirmation réglementaire sourcée |
| Table des références | En fin d'article |
| Mots-clés SEO | 3-5 cibles, densité ~7% chacune |
| Mots-clés GEO | Intégration naturelle dans le corps |
| Visuels | 1 image hero + 1 schéma/tableau minimum |
| CTA | Proposition d'entretien technique (pas commercial) |
| Meta-description | 120-160 caractères |

### Format Livre Blanc

| Élément | Standard |
|---------|----------|
| Pages | 12-30 pages |
| Résumé exécutif | 1 page |
| Contenu | Analyse + Cadre réglementaire + Recommandations |
| Annexes | Glossaire, Références, Sources |
| Design | Template institutionnel KHEPRA |
| Distribution | Téléchargement avec email (lead magnet) |
